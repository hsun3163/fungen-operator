# Recreate

To recreate is to execute the ordinary practitioner path from retained source and configuration, a declared environment, declared inputs and external requirements, and a clean declared start, then satisfy a criterion fixed before the cited run.

Default to functional equivalence unless the project explicitly requires bitwise identity. Express equivalence as observable facts a practitioner can test: the canonical path completes, declared assertions hold, output schema and meaning match, and variation remains within predeclared nondeterministic bounds.

A bounded recreation may reduce workload size but must exercise the same behavior and ordinary route. It verifies only that bounded route and behavior, not unexecuted production outputs.

Recreation does not require credentials, restricted data, services, or hardware to be stored in the project. It does require stable identities, access procedures, expected interfaces or locations, compatibility requirements, and retention adequate for the claim. If an authorized practitioner cannot obtain a required external element, state that recreation is blocked.
