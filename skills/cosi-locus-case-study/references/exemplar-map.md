# Exemplar selection map

Resolve `REPO` to the active `COSI_pecotmr` root. These are scientific patterns, not gene lists to copy.

| Pattern | Primary exemplar | What to reuse | What not to copy blindly |
|---|---|---|---|
| Concordant retained CS | `REPO/analysis/BIN1/` | strict context audit, retained-CS membership, ALT-oriented signed LD, full provenance and packet validator | BIN1 contexts, positive-direction assertion, window, LD chromosome |
| Opposing retained CS | `REPO/analysis/PICALM/` | shared variant alignment, opposing canonical `Z_acat`, retained CS tracks | Bellenguez choice, three fixed contexts, PICALM window |
| Lower-coverage sensitivity | `REPO/analysis/CASS4/` | 95/70/50 coverage audit, exact LD-purity validation, hollow/dashed sensitivity grammar | the 70% cutoff as a universal choice, foam-cell conclusion |
| Missing CS with model SNPs | `REPO/analysis/SRC/` | explicit non-CS weight markers, dashed same-SNP GWAS/eQTL connectors, missing-CS status | P0.001 as a CS, SRC-specific 12-SNP count, STARNET selection |

For each exemplar, inspect its `README.md`, input builder, notebook generator, executed notebook, validation tables, and final SVG before adapting it.

The historical structural BIN1 notebook is under the neighboring COSI repository and may guide layout only. Scientific values must come from current corrected COSI_pecotmr artifacts.
